#+title: My NixOS config

** Overview
Multi-host NixOS configuration using [[https://github.com/hercules-ci/flake-parts][flake-parts]] for modular management. Uses two nixpkgs channels (stable, unstable), [[https://github.com/nix-community/home-manager][home-manager]] for user environments, [[https://github.com/Mic92/sops-nix][sops-nix]] for secrets, and [[https://github.com/nix-community/disko][disko]] for declarative disk layouts.

** Host specification

| Name           | Description               | Type    | Arch          |
| homelab        | Workstation               | Desktop | x86_64-linux  |
| thinkpad-x1-g3 | Thinkpad X1 Extreme Gen 3 | Laptop  | x86_64-linux  |
| homeserver     | Raspberry Pi 4B           | Server  | aarch64-linux |
| homerpilab     | Raspberry Pi 4B           | Server  | aarch64-linux |
| iso            | LiveCD for setup/restore  | ISO     | x86_64-linux  |

*** homeserver services
- [[https://nextcloud.com/][Nextcloud]] - File sync, calendar, contacts
- [[https://www.home-assistant.io/][Home Assistant]] - Home automation
- [[https://docs.paperless-ngx.com/][Paperless-ngx]] - Document management with automated backups to thinkpad
- [[https://calibre-ebook.com/][Calibre]] - E-book library server
- [[https://forgejo.org/][Forgejo]] - Git forge
- [[https://tailscale.com/][Tailscale]] - VPN with auto-provisioned Let's Encrypt HTTPS via nginx reverse proxy
- [[https://github.com/nix-community/harmonia][Harmonia]] - Nix binary cache for LAN clients

*** thinkpad-x1-g3 services
- [[https://traefik.io/][Traefik]] - Local HTTPS reverse proxy for development (devenv and Docker)
- [[https://thekelleys.org.uk/dnsmasq/doc.html][dnsmasq]] - Wildcard =*.test= / =*.loc= → 127.0.0.1 for Traefik, reached only through a systemd-resolved DNS delegate
- [[https://github.com/StevenBlack/hosts][StevenBlack hosts]] - Ad/tracker blocklist in =/etc/hosts=

*** DNS
All hosts use [[https://www.freedesktop.org/software/systemd/man/latest/systemd-resolved.service.html][systemd-resolved]]: NetworkManager hands it each connection's DHCP/VPN servers, and Tailscale registers MagicDNS as a split-DNS route for the tailnet only (short names like =homerpilab= work). mDNS (=*.local=, Samba discovery) stays with Avahi; resolved's own mDNS and LLMNR are off. The thinkpad publishes =thinkpad-x1-g3.local= on Wi-Fi, which the Pis use for their remote builder.
- [[https://github.com/nix-community/disko][Disko]] - Declarative disk partitioning (btrfs, adoption mode)
- YubiKey PAM authentication (challenge-response)
- NVIDIA PRIME offload (Intel iGPU primary, NVIDIA dGPU on demand)

** Usage

*** Local Rebuilds

Enter the development shell, then use the provided commands:

#+begin_src bash
# Enter development shell
nix develop

# Rebuild NixOS system configuration
nix-switch

# Format all Nix files
nix fmt
#+end_src

*** Remote Deployment

Deploy to a remote host from thinkpad:

#+begin_src bash
nixos-rebuild switch --flake ".#homeserver" \
  --target-host piotr@homeserver \
  --build-host localhost
#+end_src

Or build directly on the Pi (recommended for RPi hosts — fetches from cache.nixos.org):

#+begin_src bash
ssh piotr@homeserver "cd ~/nix-config && git pull && sudo nixos-rebuild switch --flake .#homeserver"
#+end_src

** Adding a New Host

1. Create =hosts/{hostname}/default.nix= with the host-specific system configuration. =mkHost= already adds =modules/nixos/base.nix= (nixpkgs, home-manager, the piotr user, nix settings, locale, SSH, resolved, Tailscale) and the private sops modules. Import on top of that:
   - =./hardware-configuration.nix=
   - Profiles: =outputs.nixosModules.server= (always-on), =outputs.nixosModules.desktop= (GNOME workstation), =outputs.nixosModules.rpi4= (Raspberry Pi 4, includes =server=)
   - Features: =outputs.nixosModules.samba=, =outputs.nixosModules.wifi-watchdog=
   - Any relevant =inputs.private-nix-config.nixosModules.*= for secrets
   - Optionally: =inputs.hardware.nixosModules.{profile}=, =inputs.disko.nixosModules.disko=

2. Create =hosts/{hostname}/hardware-configuration.nix= (generate with =nixos-generate-config= or copy from an existing host)

3. Create =home/piotr/{hostname}.nix= — this is the home-manager entry point for the host:
   - Servers import =./global= (git, nix settings, CLI basics)
   - Desktop machines import =./profiles/workstation.nix= (global + emacs, direnv, firefox, fonts)
   - Add further =./features/*= as needed

4. Register the host in =parts/nixos.nix=:
   #+begin_src nix
   new-host = mkHost { hostname = "new-host"; };
   # For aarch64: mkHost { hostname = "new-host"; system = "aarch64-linux"; };
   #+end_src

5. Register the home config in =parts/home-manager.nix=:
   #+begin_src nix
   "piotr@new-host" = mkHome { username = "piotr"; hostname = "new-host"; };
   #+end_src

6. Stage all new files: =git add hosts/new-host/ home/piotr/new-host.nix= (flakes only see git-tracked files)

7. Build: =nixos-rebuild switch --flake ".#new-host"=

For Raspberry Pi hosts, see [[file:docs/rpi-setup.org][docs/rpi-setup.org]] for the full setup workflow (SD image build, USB SSD boot, sops key provisioning).

** Remote Builds

RPi hosts (aarch64) delegate builds to thinkpad-x1-g3 (x86_64) using distributed builds with QEMU emulation.

- A =builder= user on thinkpad accepts SSH connections from RPi hosts
- The builder SSH key is managed via sops-nix and deployed to =/etc/nix/builder_key=
- Thinkpad enables =boot.binfmt.emulatedSystems = [ "aarch64-linux" ]= for cross-compilation

** Secrets Management

Secrets are managed via [[https://github.com/Mic92/sops-nix][sops-nix]] with age encryption. Encrypted secrets are stored in the private repository (=nix-config-private=).

*** Key Types by Host

- *homeserver*, *homerpilab*: SSH host key (=/etc/ssh/ssh_host_ed25519_key=)
- *thinkpad-x1-g3*: Standalone age key (=/var/lib/sops-nix/key.txt=)

*** Editing Secrets

#+begin_src bash
cd ~/projects/nix-config-private
sops secrets/homeserver.yaml
#+end_src

** LiveCD ISO

A bootable LiveCD ISO for new host setup (disk partitioning, =nixos-install=) and configuration restore.

#+begin_src bash
nix build .#nixosConfigurations.iso.config.system.build.isoImage
dd if=result/iso/nixos-setup.iso of=/dev/sdX bs=4M status=progress
#+end_src

The ISO boots into a GNOME desktop with Emacs, Claude Code, git, disko, btrfs-progs, sops/age, and standard utilities.

** Directory Layout

#+begin_src
hosts/                     # Per-host NixOS configurations
  {hostname}/
    default.nix            # Host-specific system config
    disk-config.nix        # Disko declarative disk layout (optional)
    hardware-configuration.nix

home/piotr/                # Home-manager configurations
  global/                  # Shared across all hosts (git, nix settings, CLI basics)
  profiles/                # Bundles of features (workstation)
  features/                # Optional modules (emacs, direnv, firefox)
  {hostname}.nix           # Host-specific user config

modules/nixos/             # Shared NixOS modules, exported as nixosModules.*
  base.nix                 # Added to every host by mkHost
  profiles/               # server, desktop, rpi4
  features/               # user-piotr, samba, wifi-watchdog

parts/                     # Flake-parts modules (nixos, modules, iso, overlays, dev-shell, formatter, packages, templates)

overlays/modifications/    # Package overlays (auto-loaded, no registration needed)

pkgs/                      # Custom package definitions

docs/                      # Setup guides and documentation
#+end_src
